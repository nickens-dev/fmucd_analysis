# Interview results deck

`fmucd_results_draft.pptx` is an editable nine-slide draft for a ten-minute presentation. It includes timed speaker notes, an editable model-comparison chart, and tables of data and clustering results. `speaker_notes.md` provides a separate copy of the notes.

The slides summarize the completed TF-IDF/SVD validation pilot. They do not claim a completed final test or an improvement from the latest text cleanup.

`build_deck.mjs` contains the authoring function used in the Codex Artifact Session presentation environment. It expects the session presentation object and is not a standalone Node command. Source figures and detailed calculations are in `../reports/`.
