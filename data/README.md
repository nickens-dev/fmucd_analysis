# Data

Download the CSV from the [FMUCD version 1 dataset](https://data.mendeley.com/datasets/cb8d2nsjss/1) and save it here as `FMUCD.csv`.

Run `../data_exp.ipynb` to generate `clustering/`. That directory contains the two text inputs, training-task aggregate features, work-order predictors and outcomes, an exclusion audit, summary tables, a manifest, and a guide to the generated datasets.

The raw CSV and generated tables are intentionally excluded from version control. They remain available locally.

Source: Pampana et al. (2024), *Facility Management Unified Classification Database (FMUCD)*, Mendeley Data, V1, doi:10.17632/cb8d2nsjss.1. Source data license: CC BY 4.0.
